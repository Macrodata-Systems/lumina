# Deployment Instructions - Lumina v1.2

## 🛑 BLOCKED? How to Withdraw Pending Review
**Problem:** You cannot edit the Store Listing or upload a new package because your previous version (v1.1) is locked in "Pending review".
**Solution:** You must **Withdraw** the submission first.

1.  **Click the Three Dots (⋮)** in the top-right corner of the Developer Dashboard (near your profile icon).
2.  Select **"Cancel review"** (or "Withdraw package").
3.  Confirm the action.
4.  **Result:** The status will change to **"Draft"**. You can now edit the description and upload the new `lumina-v1.2.zip`.

---

## ⚠️ Critical: Update Store Listing Text
Once you are back in **Draft** mode:
1.  **Go to "Store Listing"**.
2.  **Update the Description** to remove all references to "Pro License", "Payment", or "Freemium".
    *   *Reason:* v1.2 is fully unlocked/free (BYOK). If the text says "license required", Google will reject it for "Misleading Functionality".
3.  **Recommended Text:**
    > **Lumina - AI Copilot for the Web**
    >
    > Instantly analyze the content of any tab. Lumina sees what you see and explains it in seconds.
    >
    > **✨ Key Features**
    > *   **Multi-Model Support:** Gemini, ChatGPT, Claude, Grok, DeepSeek.
    > *   **Visual Analysis:** Screenshot analysis for charts and UIs.
    > *   **Privacy First:** Runs locally in your browser.
    > *   **BYOK (Bring Your Own Key):** Free to use with your own API keys. No subscriptions required.

---

## 🚀 How to Upload v1.2
1.  **Go to "Package"** (left sidebar).
2.  Click **"Upload new package"**.
3.  Select `lumina-v1.2.zip` (located in your root folder).
    *   *Note:* Ensure the version number in the dashboard updates to **1.2**.

## Is it Lightweight?
**YES.** < 500KB. No external dependencies.
